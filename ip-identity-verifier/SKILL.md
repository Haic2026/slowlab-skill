# IP Identity Verifier — lala 辨识度自动校验

## 用途
把"每版人工盯识别度"升级为机器可复现关卡：任何生成图交付前，必须跑一次本校验，确认与 IP 权威图（references/theme-style.jpg）的主题风格与人物辨识度一致（≥86%），防止 IP 形象漂移（一版一个样）。

## 阈值（用户指定）
- 综合辨识度 **≥86%** → 判定通过，可交付
- **<86%** → 判定不通过，强制重绘（按 shulanjing §2.9-P3 增量修正，只改漂移维度）

## 六维评分（V1.3 重构）
| 维度 | 权重 | 含义 |
|---|---|---|
| 角色色(毛色家族) | 30% | dark(灰黑深棕)/warm(棕褐漂移) 占比对比——**漂移主判别** |
| 毛色区占比 | 10% | 低饱和暗区在角色本体中占比对比（取代色相重叠：低饱和毛色的色相是噪声，旧色相被帽檐/枝干道具色带偏） |
| 明度结构 | 8% | 粗亮度直方图（8 桶）相似度——构图鲁棒 |
| 低饱和 | 10% | 平均饱和度均低于 0.35 且接近 |
| 质感 | 7% | 边缘密度接近（手绘纸感/彩铅线条代理） |
| 语义 | 35% | LLM 视觉五维比对：毛色/长爪/脸部/身形/气质（**人物辨识度核心**） |

## V1.3 关键修复
1. **角色主体裁剪**：BFS 取"低饱和暗色"最大连通域（外扩 10%）——剔除草地/天空/留白背景污染（V1.2 网格法只框最密小块，导致误切）
2. **色相重叠维度废弃**：低饱和灰黑毛色的色相是无意义噪声（堆随机桶）；且旧维度实际在比"帽檐 vs 枝干"的道具色，替换为"毛色区占比"
3. **语义权重升至 35%**：人物辨识度本质是 §2.8 五维（毛色/长爪/脸部/身形/气质），LLM 比对为主、像素佐证为辅
4. 明度粗化至 8 桶（构图鲁棒）

## 用法
```bash
python ip_identity_checker.py <生成图路径> [权威图路径] [语义分0~1]
# 默认权威图 = shulanjing-design-skill/references/theme-style.jpg
# 默认语义分 = 0.85（流水线内由 LLM Read 两图描述比对后传入）
```

## 流水线集成（强制）
1. 每次生成图后，先跑脚本取视觉分
2. 用 LLM Read 生成图与权威图描述，比对五维（毛色/长爪/脸部/身形/气质），得出语义分（0~1）
3. 脚本合并输出综合辨识度与判定
4. 判定"不通过" → 按失败维度增量重绘，重绘后再校验；定稿复检（§6.1）同样要过本校验

## 有效性验证记录（V1.3 实测）
- 达标样本（v17 晒太阳）：**87.5% → 通过**（角色色 90.4 / 毛色区 69.7 / 低饱和 81 / 质感 99.9 / 语义 95）
- 漂移样本（v7 棕褐熊色）：**62.7% → 拦截**（角色色 58.7 / 语义 76 双低）
- 判别力：达标 ≥86、漂移 <86，两样本分离度 24.8 分，可复现
