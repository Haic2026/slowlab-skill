# FANBUBAO Skill — 树懒精帆布包专属设计

帆布包是 lala 文创首条产品线。本 Skill 只做一件事：**把 lala 简图放在帆布包的合理、时尚位置**。

## 核心逻辑（流水线）

1. **输入解析**：读取帆布包图，识别袋型（大托特/中托特/小包/窄长袋）、尺寸、袋面颜色、已有印刷物（标语/LOGO）。
2. **简图生成**（复用 lala skill）：
   - 双参考图：`shulanjing-design-skill/references/lala-main-v4.png`（形象）+ `lala-turnaround-v4.png`（色卡）
   - 输出**简化图案**：干净纯色底（米白）、主体独立可抠图、轮廓干净、无复杂场景（印花简图不追求插画完整度）
   - 三强制句：① 所有四肢爪子统一纯黑细长爪（无白尖无条纹）② 背景纯色米白、无斑点颗粒 ③ 恰好四条肢体
   - 色彩锚点（V4 色卡）：头深棕 / 身体暖灰褐 / 腹部米白 / 左臂灰褐 / 右臂深暖红棕 / 墨镜斑深棕黑 / 面中暖米白 / 爪纯黑
3. **位置决策**：按「袋型位置规则」选位（合理 + 时尚）。
4. **效果图合成**：image_edit（参考图 = 帆布包原图 + lala 简图），把简图印到指定位置。
5. **校验链**（复用 ip-identity-verifier + 文字拼写）：
   - L0：标语 OCR 逐字母（英文标语如 "live unrushed" 必须逐字母拼写精确）；图案无残缺
   - L1：图案本体辨识度 ≥86（ip_identity_checker，**产品图按图案本体精细裁切口径**，整图分天然偏低）
   - 位置检查：图案占比 / 四周留白 / 不跨袋缝与袋口 / 不遮提手
6. **交付**：固定 6 项 + 校验结论行 + 工厂印刷备注。
7. **归档**：prompt / run-log / 效果图链接写入本技能 outputs/ 与 GitHub（Haic2026/slowlab-skill）。

## 袋型位置规则（时尚向，市场验证）

| 袋型 | 判定 | 推荐位置 | 图案占袋面 | 说明 |
|---|---|---|---|---|
| 大托特 | 宽 >35cm | **居中偏上** | 45–60% | 主视觉区=第一视线落点；IP+Slogan 组合最带货 |
| 中托特 | 宽 25–35cm | 居中 或 右上 | 35–45% | 与提手呼应，右上位更时装感 |
| 小包/手袋 | 宽 <25cm | **右下角小标** | 20–30% | 小图点缀，低调文艺 |
| 窄长袋 | 高>宽 | 上 1/3 居中 | 30–40% | 重心上移，避免下坠感 |

### 时尚原则（每条都是硬约束）
1. **黄金位**：图案几何中心 ≈ 袋面高度的 50–58%（视线焦点带）。
2. **留白**：图案四周留白 ≥ 袋面宽 8%；单袋面不塞满，留白=高级感。
3. **不跨缝**：图案严禁越过袋身缝线、袋口边缘、提手根。
4. **单一主图**：一个袋面最多 1 处主图 + 0–1 处小标（如角落 "SlowLab"）；禁止堆叠。
5. **色彩呼应**：图案与袋面颜色同色系（浅蓝袋面 → 低饱和暖色图案）或高对比点缀，禁止高饱和撞色。
6. **不对称更时尚**：非居中位优先右上/右下（避开提手侧），左胸位留给 LOGO。
7. **文字规则**：袋面已有标语保留且不重叠主图；新加文字 ≤1 处、居中或角位；英文标语逐字母拼写精确。

## 简图生成 Prompt 模板（固定块 + 场景变量）

```
【形象锚点】以参考图 lala-main-v4 为形象模板、lala-turnaround-v4 为配色基准；
【简图要求】生成可印花的简化图案：纯色米白底、主体独立可抠图、轮廓干净利落、
线条最细≥1.2mm（避免细碎短线）、无复杂场景背景；
【色彩】头深棕/身体暖灰褐/腹部米白/左臂灰褐/右臂深暖红棕(禁浅粉)/墨镜斑深棕黑清晰/面中暖米白/爪纯黑；
【三强制】所有四肢爪子统一纯黑细长爪无白尖无条纹；画面绝对干净无斑点污渍；恰好四条肢体；
【场景变量】<本次：姿态/动作/道具/文字（每处文字中文引号标注、逐字正确、每处只出现一次）>
【负面】Q版幼态/大圆眼/腮红/毛绒/3D/高饱和糖果色/悬挂树上/条纹爪/多余肢体/斑点/水印/其他文字
```

## 效果图合成 Prompt 要点

- 参考图 1 = 帆布包原图（保留款式与袋面颜色）；参考图 2 = lala 简图
- 明确写：图案印在袋面**<位置>**、约占袋面**<比例>**、**<相对标语/提手的位置关系>**
- 去除原稿上的尺寸标注/编号/稿号等规格文字；保留袋面原有标语（若存在，逐字母拼写写死）
- 背景：干净纯色产品图背景（浅灰/白），突出包与图案

## 校验清单（交付前必过）

- [ ] 标语/文字：OCR 逐字母/逐字正确、无重复（L0）
- [ ] 图案本体辨识度 ≥86（ip_identity_checker，精细裁切 lala 本体）
- [ ] 位置：图案占比符合袋型规则、四周留白 ≥8%、不跨缝线/袋口/提手
- [ ] 姿态：4 肢、黑线爪统一、无斑点异物
- [ ] 时尚性：单一主图、色彩呼应、留白高级感（目检）

## 输出交付格式（固定 6 项 + 校验结论）

```
正向绘图Prompt（场景变量摘要）：
负面Prompt（引用固定负面词）：
图案类型：B 印花图案（帆布包）
推荐画布比例：（按袋型实拍图比例，通常 4:5 / 1:1）
工厂印刷备注：主体独立可抠图；线宽≥1.2mm；图案与袋口/缝线安全距离≥3mm；
              数码直喷优先，图案不跨缝线；标语字体版权商用授权确认
适用产品：帆布托特包 / 手袋 / 帆布袋
+ 校验结论行：文字 / 辨识度 / 位置 / 肢体 / 爪子 / 斑点水印 逐项 通过|失败
```
