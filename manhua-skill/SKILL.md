# MANHUA Skill — lala 慢生活哲理 9 格小漫画

lala 的叙事产品线。把"慢生活哲理"变成**有深度、有内容、不鸡汤**的 9 格小漫画。

## 核心流程（流水线）

1. **选题查重（先查再用，防审美疲劳）**：从「慢生活哲理主题库」选/创主题后，**必须读 `references/usage-log.md`**，按 R1-R6 铁律避开冷却池内的场景/动作/道具/时段/句式；场景从"布景扩容库"选，动作从"未用动作池"选；写出的分镜表先自查"与最近 2 套零重复"才进入生成。
2. **脚本生成**：写出 9 格叙事脚本（起→承→细节→转→领悟→回应→升华→余韵→留白），台词克制、结尾金句或开放式留白；**金句句式避开最近 3 套已用句式**。
3. **分镜设计**：每格定「景别 + 布景 + lala 姿势/情绪 + 台词」；镜头语言（全景/中景/近景/特写、视角、留白构图）；**lala 核心动作 ≤5 个且全部来自未用动作池**。
4. **形象锁定**：调 shulanjing-design-skill——双参考图（lala-main-v4 形象 + lala-turnaround-v4 色卡）+ 三强制句（黑线爪/干净/4肢）+ 色彩锚点 + 情绪库嘴线（喜悦上扬/困平线/惊小圆/哀下撇/呆圆点/平静短弧）。
5. **9 图生成**：image_edit 双参考逐格生成，全部 **3:4 竖版**；同故事共享形象与色板与背景纸色。
6. **校验链**：每格 L0（文字 OCR/肢体/水印/风格饱和度）→ L1（图案本体辨识度 ≥86）+ 跨格连续性校验 + **去重复查（对照 usage-log：主场景/核心动作/道具/时段/句式逐项过 R1-R6）** + 背景纸色/道具细节合规。
7. **交付**：脚本全文 + 分镜表 + 9 张编号插画（01–09）+ 校验结论行（含"去重"项）。
8. **归档**：脚本/分镜/prompt/9 图链接写入本技能 outputs/ 与 GitHub（Haic2026/slowlab-skill）；**同步把本套的主场景/核心动作/道具/时段/金句句式追加进 `references/usage-log.md` 已用清单，并更新冷却池**。

## 脚本规格（慢生活哲理小故事）

### 主题库（可自由扩展，但守住"生活观察+轻微反转+留白"）
- 等待｜慢慢来｜发呆的时间｜一杯咖啡的时间｜与自己和解｜不追赶｜独处｜小确幸｜雨天｜旧物｜门口的长椅｜晚霞

### 9 格叙事结构（每套漫画固定骨架）
| 格 | 功能 | 内容要求 |
|---|---|---|
| 1 | 起 | 日常场景引入（环境+人物状态），留一个微悬念 |
| 2 | 承 | 一个小事件/发现（动作推进，不着急） |
| 3 | 细节 | 观察细节（镜头拉近，画面安静下来） |
| 4 | 转 | 环境/情绪微变（云动、风起、人走过） |
| 5 | 领悟 | 领悟时刻（画面最安静，人物停顿） |
| 6 | 回应 | 人物松弛回应（一个缓慢动作） |
| 7 | 升华 | 哲思定格（金句台词或纯画面情绪高点） |
| 8 | 余韵 | 场景余韵（道具/环境呼应前文） |
| 9 | 留白 | 开放式结尾（回味，不把话说满，常无字） |

### 深度要求（硬约束）
- **不写鸡汤**：拒绝"努力就会成功"式说教；写"生活观察 + 轻微反转 + 留白"的哲理感。
- 台词克制：每格 ≤15 字；金句只放 1 处（第 7 格）；可做无字格（第 9 格常无字）。
- 内容有生活质感：场景/道具/行为来自真实日常（煮咖啡、等公交、翻旧书、晒被子）。
- lala 气质贯穿：松弛、放空、淡淡冷感，去可爱化。

## 分镜表模板

```
| 格 | 景别 | 布景 | lala 姿势/情绪 | 台词/旁白 | 构图要点 |
|---|---|---|---|---|---|
| 1 | 全景 | 窗边晨光 | 坐在窗台发呆 | （无字） | 大面积留白，人物占下 1/3 |
| ... |
```

- **景别**：全景（交代环境）／中景（姿态）／近景（表情）／特写（道具细节）
- **布景库（扩容）**：家／阳台／厨房／菜园／旧书房／书店阁楼／咖啡馆／公园长椅／河边／山顶／天台／窗边／雨天窗台／草地／公交站／夜市／花市／邮局／画室／洗衣房／江边／路灯下／杂货铺／图书馆／泡脚木桶前／火车窗边
- **动作池（优先未用）**：浇花／晾晒／剥橘子／写信／擦窗／扫落叶／织毛线／整理抽屉／贴邮票／修自行车／逗鱼／叠衣服／数星星／画速写／泡脚／听收音机／发呆／散步／回头／伸懒腰／盖毯子（近 2 套已用动作见 usage-log 冷却池，禁用）
- **镜头语言**：平视为主；转折格可俯视（放空感）或低视角（宁静感）；留白构图 ≥40%

## 防重复（Anti-Repeat，用户强制，2026-09-14）

**每套开工前必须读 `references/usage-log.md`**，R1-R6 铁律一览：
- R1 主场景：连续 3 套不得复用；一套仅 1 个主场景
- R2 核心动作：连续 2 套不得复用；每套 ≤5 个
- R3 道具：连续 2 套不得复用
- R4 金句句式：连续 3 套不重复
- R5 标志构图：连续 3 套不复用
- R6 开场时段：连续 2 套不得同段开场

选材顺序：**先查冷却池 → 从布景扩容库/动作池挑未用项 → 写分镜 → 对照最近 2 套自查零重复**。套与套之间的"场景/动作/道具/时段/句式"重复是硬伤，校验不过即返工改脚本（不消耗生图）。

## 场景配色与纸感背景（用户 2026-09-15 强制，替代单一米白底）

**每格背景 = 场景专属的多巴胺纸感纯色**，禁止一律米白、禁止灰暗单调：
1. **纸感纯色底**：整幅背景为**单一纯色**（马卡龙/多巴胺纸色系），带**纸张颗粒哑光质感**（类似出版纸/手工纸，细腻不光滑），人物与道具浮于纸色之上。
2. **场景-情绪-配色映射**（选色三原则，依据 aesthetic-foundations 美学）：
   - 暖情绪/暖时段（午后、晨光、厨房、阳台、夜市）→ 暖纸色（奶黄、珊瑚粉、奶油橙、蜜桃）
   - 冷情绪/静场景（雨天、河边、夜晚、图书馆、发呆）→ 冷纸色（雾霾蓝、淡青、香芋紫、灰蓝绿）
   - 中性怀旧（旧物、书店、杂货铺、邮局）→ 燕麦米、浅灰褐、旧纸色
   - 整套 9 格共享 1 个主背景纸色（可随格 1-2 档明度微变，禁止每格换色跳变）。
3. **参考质感**（只学气质，不抄构图）：用户参考图为"浅紫纸纹纯色底 + 奶黄圆桌 + 道具细节饱满（红酒杯/烤虾串/绿边盘/酒标）"——背景纸感 + 道具质感细节为本条目的。

## 道具细节规范（用户 2026-09-15 强制，替代"道具 ≤1 件"）

1. **数量**：每格 1-3 件场景道具，全部来自场景语义（不做装饰堆砌）。
2. **细节饱满**：道具要有**结构细节与材质暗示**——盘有描边、杯有杯垫、瓶有标签、书有书签、叶有脉络、花有花蕊；拒绝干瘪孤立的轮廓。
3. **合理性**：道具与动作/场景逻辑自洽（喝咖啡→杯+杯垫+小碟；晾晒→夹子+晾衣绳+影子；写信→信纸+邮票+钢笔）。
4. **主次**：道具是氛围点缀，不抢 lala 主体、不遮挡面部与爪子；留白仍 ≥40%。

## 生成 Prompt 模板（每格 = 形象块 + 场景变量块）

```
【形象锚点】以参考图 lala-main-v4 为形象模板、lala-turnaround-v4 为配色基准；
【色彩】头深棕/身体暖灰褐/腹部米白/左臂灰褐/右臂深暖红棕(禁浅粉)/墨镜斑深棕黑清晰/面中暖米白/爪纯黑；
【三强制】所有四肢爪子统一纯黑细长爪无白尖无条纹；画面绝对干净无斑点污渍；恰好四条肢体；
【情绪】嘴线按情绪库：<上扬浅笑/放松平线/微张小圆/嘴角下撇/小圆点>；姿态：<坐/站/躺/走 + 手部动作 + 体态>；
【背景纸色】<主纸色 + 明度档>：整幅单一纯色纸感底（如浅紫/奶黄/雾霾蓝…），带细腻纸张颗粒哑光质感，无任何环境杂物、无渐变；
【场景变量】第 <N> 格：<景别>、<布景描述>、<时间光感>、<道具（1-3 件，写出材质与细节）>、<台词（中文引号标注、逐字正确、每处只出现一次，无字格写"无文字">；
【风格】手绘绘本风：纸感纯色底 + 纸张颗粒、彩铅蜡笔线条、低饱和暖调、大量留白、拼贴质感；
【负面】Q版幼态/大圆眼/腮红/毛绒/3D/高饱和糖果色/悬挂树上/条纹爪/多余肢体/斑点/水印/其他多余文字/跨格元素错乱/灰暗单调背景/环境杂物堆砌
```

## 连续性校验（9 格成一套的关键）

- [ ] **lala 外观一致**：每格毛色/墨镜斑/黑线爪/头身比相同（逐格 vs 权威图辨识度 ≥86）
- [ ] **场景连续**：同一故事主场景/道具不突变；时间线（晨/午/暮/夜）光感自洽
- [ ] **色板一致**：9 格共用固定色板，无单格色彩漂移
- [ ] **人物比例**：同景别下 lala 大小一致；景别变化有叙事意图
- [ ] **文字连续**：台词格 OCR 逐字正确、无重复；无字格确无文字
- [ ] **风格统一**：纸感/线条/留白手法 9 格一致
- [ ] **背景纸色合规**：9 格共享 1 个场景语义纸色、纸张颗粒哑光质感、无灰暗单调（新增）
- [ ] **道具细节合规**：每格 1-3 件、有材质细节、与场景逻辑自洽、不抢主体（新增）
- [ ] **去重通过（Anti-Repeat）**：对照 usage-log.md——本套主场景/核心动作/道具/开场时段/金句句式 与最近 2-3 套零冲突（R1-R6 全过）
