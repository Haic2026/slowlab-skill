# MANHUA Skill — lala 慢生活哲理 6 格小漫画

lala 的叙事产品线。把"慢生活哲理"变成**有深度、有内容、不鸡汤**的 6 格小漫画。

## 核心流程（流水线）

1. **脚本生成**：从「慢生活哲理主题库」选/创一个主题，写出 6 格叙事脚本（起→承→转→合→升华→留白），台词克制、结尾金句或开放式留白。
2. **分镜设计**：每格定「景别 + 布景 + lala 姿势/情绪 + 台词」；镜头语言（全景/中景/近景/特写、视角、留白构图）。
3. **形象锁定**：调 shulanjing-design-skill——双参考图（lala-main-v4 形象 + lala-turnaround-v4 色卡）+ 三强制句（黑线爪/干净/4肢）+ 色彩锚点 + 情绪库嘴线（喜悦上扬/困平线/惊小圆/哀下撇/呆圆点/平静短弧）。
4. **6 图生成**：image_edit 双参考逐格生成，全部 **3:4 竖版**；同故事共享形象与色板。
5. **校验链**：每格 L0（文字 OCR/肢体/水印）→ L1（图案本体辨识度 ≥86）+ 跨格连续性校验。
6. **交付**：脚本全文 + 分镜表 + 6 张编号插画（01–06）+ 校验结论行。
7. **归档**：脚本/分镜/prompt/6 图链接写入本技能 outputs/ 与 GitHub（Haic2026/slowlab-skill）。

## 脚本规格（慢生活哲理小故事）

### 主题库（可自由扩展，但守住"生活观察+轻微反转+留白"）
- 等待｜慢慢来｜发呆的时间｜一杯咖啡的时间｜与自己和解｜不追赶｜独处｜小确幸｜雨天｜旧物｜门口的长椅｜晚霞

### 6 格叙事结构（每套漫画固定骨架）
| 格 | 功能 | 内容要求 |
|---|---|---|
| 1 | 起 | 日常场景引入（环境+人物状态），留一个微悬念 |
| 2 | 承 | 一个小事件/发现（动作推进，不着急） |
| 3 | 转 | 观察细节/领悟时刻（画面安静下来，镜头拉近） |
| 4 | 合 | 人物状态/动作变化（松弛回应） |
| 5 | 升华 | 哲思定格（金句台词或纯画面情绪高点） |
| 6 | 留白 | 开放式结尾（回味，不把话说满） |

### 深度要求（硬约束）
- **不写鸡汤**：拒绝"努力就会成功"式说教；写"生活观察 + 轻微反转 + 留白"的哲理感。
- 台词克制：每格 ≤15 字；金句只放 1 处（第 5 格）；可做无字格（第 6 格常无字）。
- 内容有生活质感：场景/道具/行为来自真实日常（煮咖啡、等公交、翻旧书、晒被子）。
- lala 气质贯穿：松弛、放空、淡淡冷感，去可爱化。

## 分镜表模板

```
| 格 | 景别 | 布景 | lala 姿势/情绪 | 台词/旁白 | 构图要点 |
|---|---|---|---|---|---|
| 1 | 全景 | 窗边晨光 | 坐在窗台发呆 | （无字） | 大面积留白，人物占下 1/3 |
| ... |
```

- **景别**：全景（交代环境）／中景（姿态）／近景（表情）／特写（道具细节）
- **布景库**：家／咖啡馆／书店／公园长椅／窗边／雨天窗台／草地／公交站／菜市场／天台
- **镜头语言**：平视为主；转折格可俯视（放空感）或低视角（宁静感）；留白构图 ≥40%

## 生成 Prompt 模板（每格 = 形象块 + 场景变量块）

```
【形象锚点】以参考图 lala-main-v4 为形象模板、lala-turnaround-v4 为配色基准；
【色彩】头深棕/身体暖灰褐/腹部米白/左臂灰褐/右臂深暖红棕(禁浅粉)/墨镜斑深棕黑清晰/面中暖米白/爪纯黑；
【三强制】所有四肢爪子统一纯黑细长爪无白尖无条纹；画面绝对干净无斑点污渍；恰好四条肢体；
【情绪】嘴线按情绪库：<上扬浅笑/放松平线/微张小圆/嘴角下撇/小圆点>；姿态：<坐/站/躺/走 + 手部动作 + 体态>；
【场景变量】第 <N> 格：<景别>、<布景描述>、<时间光感>、<道具>、<台词（中文引号标注、逐字正确、每处只出现一次，无字格写"无文字"）>；
【风格】手绘绘本风：米白旧纸底、纸张颗粒、彩铅蜡笔线条、低饱和暖调、大量留白、拼贴质感；
【负面】Q版幼态/大圆眼/腮红/毛绒/3D/高饱和糖果色/悬挂树上/条纹爪/多余肢体/斑点/水印/其他多余文字/跨格元素错乱
```

## 连续性校验（6 格成一套的关键）

- [ ] **lala 外观一致**：每格毛色/墨镜斑/黑线爪/头身比相同（逐格 vs 权威图辨识度 ≥86）
- [ ] **场景连续**：同一故事主场景/道具不突变；时间线（晨/午/暮）光感自洽
- [ ] **色板一致**：6 格共用固定色板，无单格色彩漂移
- [ ] **人物比例**：同景别下 lala 大小一致；景别变化有叙事意图
- [ ] **文字连续**：台词格 OCR 逐字正确、无重复；无字格确无文字
- [ ] **风格统一**：纸感/线条/留白手法 6 格一致

## 输出交付格式（固定 6 项 + 校验结论）

```
脚本全文：（6 格叙事，含金句）
分镜表：（6 行，景别/布景/姿势/台词/构图）
正向绘图Prompt：（形象块引用 + 每格场景变量摘要）
负面Prompt：（引用固定负面词）
图案类型：B 印花图案（漫画分镜插画）
推荐画布比例：3:4 竖版（每格一致）
+ 校验结论行：形象一致性 / 文字 / 肢体 / 爪子 / 斑点水印 / 场景连续性 逐项 通过|失败
```
