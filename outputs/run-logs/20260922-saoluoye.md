# 20260922 第十八套漫画《扫不完的落叶》归档

## 主题
扫不完的落叶 · 秋夜路灯下（9月下旬秋分季，适合当下发布）

## 流量钩子（新 skill 规则首套实践）
- **主钩子：微小反转**——以为 lala 在认真扫落叶 → 风一吹全散了 → 它干脆不扫了，把扫帚靠路灯边，"扫不完的叶子，正好留给风"
- **辅钩子：拟人对话**——格5 想法云朵内画小叶子图形，台词"叶子说，不用着急。"
- **金句**："扫不完的叶子，正好留给风。"（句式：XX，正好留给XX，未用✅；口播感：能接"原来…"✅）

## 场景/纸色/时段
- 主场景：路灯下（✅ 未用）
- 纸色：暮紫/暗紫灰纸感纯色（秋夜路灯下的合适色，按场景-情绪-配色映射）✅
- 时段：黄昏→夜晚（路灯亮起）✅ 未冷却

## Anti-Repeat 核验（对照 usage-log）
- 动作：扫落叶/停步看叶/放扫帚/坐下裹围巾 ✅ 全未用
- 道具：扫帚/落叶/路灯/围巾 ✅ 全未用
- R1-R6 全过
