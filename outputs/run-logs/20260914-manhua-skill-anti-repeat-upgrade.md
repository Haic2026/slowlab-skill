# 20260914-manhua-skill 升级：Anti-Repeat 场景/动作去重机制

## 需求来源
用户反馈：多套漫画场景/动作重复（咖啡馆/窗边、看热气/看倒影/端杯喝/看云反复出现），大众会审美疲劳。要求修改 skill 防重复。

## 改动文件（4 个）

### 1. manhua-skill/SKILL.md
- 流水线新增第 1 步「选题查重」：先读 usage-log.md，按 R1-R6 铁律避开冷却池
- 布景库扩容（10 → 24 个场景）
- 新增「防重复（Anti-Repeat）」章节：R1 主场景冷却 3 套 / R2 核心动作冷却 2 套 / R3 道具冷却 2 套 / R4 金句句式冷却 3 套 / R5 标志构图冷却 3 套 / R6 开场时段冷却 2 套
- 新增 lala 动作池（已用禁用 + 未用优先）
- 连续性校验新增「去重通过（Anti-Repeat）」项
- 归档步骤要求同步更新 usage-log.md

### 2. manhua-skill/references/usage-log.md（新建）
