# 20260915-manhua-skill 场景升级：多巴胺纸感纯色底 + 道具细节饱满

## 需求来源
用户反馈：场景色彩单调，要求背景改为"纸张出版的颜色"（参考图：浅紫纸纹纯色底 + 奶黄圆桌 + 红酒杯/烤虾串/绿边盘/酒标等细节饱满配物），颜色按场景语义搭配（美学原则），配物小细节更饱满合理。

## 改动文件（3 个）

### 1. manhua-skill/SKILL.md
- 新增「场景配色与纸感背景」章节：每格背景 = 场景专属多巴胺纸感纯色（单一纯色 + 纸张颗粒哑光质感），选色三原则（暖情绪/暖时段→暖纸色，冷情绪/静场景→冷纸色，中性怀旧→燕麦米系）；整套共享 1 个主纸色
- 新增「道具细节规范」：1-3 件/格、有结构细节与材质暗示、与动作场景逻辑自洽、不抢主体
- Prompt 模板：【风格】行改为纸感纯色底；【背景纸色】行新增强制项；负面词加"灰暗单调背景/环境杂物堆砌"
- 校验链新增：背景纸色合规、道具细节合规两项

### 2. manhua-skill/references/story-template.md
