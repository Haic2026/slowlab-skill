## 修正记录（本轮 L0 发现与纠正）
1. 格3 首版背景暖黄渐变+光晕 → 重画纯色底；格3 二次版白色尖爪（举爪姿势触发）→ 重画黑线爪定稿
2. 格4 首版出现墙面地面分界线 → 重画纯色底
3. 格7/8 盘腿/抱膝坐姿均触发白色尖爪 → 全部改站立姿势重画后爪子纯黑 ✅
4. **经验固化：坐姿（尤其盘腿/抱膝）为白尖爪高发姿势，凡坐姿格必须写死"爪尖纯黑"或改站立**
