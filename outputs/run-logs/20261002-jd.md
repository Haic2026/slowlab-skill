# 20261002 第二十七套漫画《鸡蛋沉底，才算新鲜》归档（教学局第3期）

## 定位
lala 教学局 · 一天一个生活小技巧 · 第 3 期（2026-10-02，流量优先期）

## 技巧
水浮法判断鸡蛋新鲜度：新鲜蛋沉底横躺；放久了会立起来（尽快吃）；坏蛋/不新鲜蛋浮上水面（别吃）
- 痛点：冰箱里的蛋放了多久，谁也不知道
- 妙招：一碗清水，蛋放进去——横躺沉底=新鲜，竖立=尽快吃，浮起=别吃
- 口诀："鸡蛋沉底，才算新鲜。"（句式：XX沉底，才算XX，未用✅）
- 真实可落地：✅ 经典科普（水浮法），真实可验证
