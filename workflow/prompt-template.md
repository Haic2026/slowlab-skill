# 树懒精 SlowLab — Prompt 模板（V0.8，token 最省）

> 用法：每次生成时 = 固定块（A/B/C/D/E/F 按需拼装）+ 场景变量段（仅写本次差异，50~120 字）。
> 禁止在每轮回复/交付中重复全量固定块；完整拼接后的 prompt 只写入归档。

## 固定块 A｜lala 形象锚点（必选）
lala（树懒精家族成员）：抽象极简人形树懒；毛色灰黑深棕大地色（禁棕褐、橙红、绿蓝等其他色）；修长长爪带白色爪尖；面部单根极简眼睑弧线/闭眼浅笑（禁大圆眼、腮红）；松弛放空冷感；头身比稳定。

## 固定块 B｜手绘绘本质感（风格 D 必选；A/B/C 风格按需）
米白旧纸底、纸张颗粒、彩铅蜡笔手绘线条、粗粝手绘边缘、拼贴质感、低饱和哑光、大量留白。

## 固定块 C｜肢体解剖硬约束（必选）
恰好两条手臂两条腿共四条肢体；四肢轮廓完全分离、互不重叠、清晰可数；绝无多余手臂、多余爪子、第三只脚、重复腿部、腿部交叠错乱；道具与肢体接触自然、不抢主体。

## 固定块 D｜文字全大写模板（有文字时必选；逐字母写法已固化）
必须纯大写排版：第一行是 N 个全部大写且高度一致的字母（逐字母写出，如 S L O W），第二行是 M 个全部大写且高度一致的字母（逐字母写出，如 S U N），两行居中对齐；松弛随性的手写体、炭黑色、清晰可读；每个字母都是大写形态，不得出现任何小写字母。

## 固定块 E｜水印禁令（必选）
画面任何位置绝对不出现水印、来源标识、签名、角标或任何文字标记。

## 固定块 F｜背景色板（背景/版式场景必选）
背景与版式使用固定色板：炭黑 #0B0908｜暖米白 #CCBFB8｜雾灰 #D0D7D6｜深炭绿 #1F231C｜咖啡棕 #3C3327；绘本风格可加拓展色旧纸米白 #E8DFCF｜淡灰褐 #B8AFA3｜铅笔灰 #6E6E6E；低饱和、明度层级清晰、面积对比合理、无糖果色。

## 固定块 G｜负面 Prompt（必选，引用文件不重复全文）
固定负面词见 references/negative-prompt.md；视觉相关轮次追加：肢体混乱、多余手臂、多余爪子、第三只脚、重复腿部、腿部交叠错乱、断肢、畸形连接、身体扭曲、重心失衡、道具漂浮、手部错位、动作东拉西扯、水印、来源标识、签名、角标。

## 场景变量段（每次只写这一段，50~120 字）
结构：场景/姿态（1 句）→ 道具（按用户指定，默认无）→ 文字（有则按固定块 D 写法）→ 画幅（工具参数，不写进 prompt）→ 其他用户指定细节。

示例：
"lala 在公园草地午后晒太阳，半躺草地放松舒展；头戴宽边草帽，帽檐压低遮住双眼只露嘴角浅笑（遮挡类见 §2.9-P4 双保险）；无其他道具；上方留白渲染固定块 D 的 SLOW/SUN 两行。"

## 拼接顺序
[场景变量段] + 固定块 A + B + C +（D 若有文字）+ E +（F 若涉及背景色）+ 负面词引用（G）。
