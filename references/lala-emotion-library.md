## 核心方法（V7 最终版，唯一有效路线）

1. **姿态 + 嘴线全部由 image_edit 生成**：每张指定情绪姿态 + 嘴形描述
2. **双参考图**：`lala-main-v4`（形象模板）+ `lala-turnaround-v4`（三视图+色卡，色彩基准）——色彩精确锚定，单参考图色彩会漂移
3. **prompt 色彩锚点**（必带，源自 V4 实测色卡）：头深棕 (55,46,31) / 身体暖灰褐 (135,126,107) / 腹部米白 / 画面左臂灰褐 / 画面右臂深暖红 (146,101,62)（禁止浅粉）/ 墨镜斑深棕黑 / 面中暖米白 / 爪纯黑 / 背景米白。低饱和暖调，禁止提亮
4. **零 PIL**：不画眼线、不画嘴、不盖带、不删斑、不改色——所有后处理禁用（PIL 盖带=斑点主犯；色互换破坏渐变）
5. **prompt 三强制句**（每张必带）：
   - 爪子："所有四肢爪子统一为黑色细长爪（黑线爪），无白色尖甲、无黑白条纹，四爪完全一致"
   - 干净："背景纯色米白，画面绝对干净，无任何斑点污渍颗粒"
   - 肢体："恰好四条肢体"
6. **出图后校验链**：
   - 辨识度 ≥86（ip_identity_checker vs lala-main-v4，语义 0.9）
   - **色彩检测（P8）**：主体行定位(rowcov>100) → 分区域中位色 → vs V4 基准欧氏距离 >60 标记偏差 → 只强化漂移部位颜色词重绘；区域采样必须排除背景像素（背景米白拉偏中位数）
   - 爪部拼图目检（纯黑单色统一）
   - 边缘斑点程序扫描 + 异物单查（口水/泪珠/条纹 → 单张重绘加禁词）
7. 情绪差异**以姿态为主载体**（模型对单线眼微表情不可控）；嘴线差异为辅助（上扬/平线/圆点/微张/下撇）

## 线条情绪规律（市场向，用于 prompt 嘴线描述）

- 喜悦 = 嘴角上扬浅笑（上翘弧）
- 困/乏 = 放松平线（不笑）
- 惊 = 微张小圆
- 哀/委屈 = 嘴角下垂下撇
- 呆 = 小圆点
- 平静 = 极简短弧浅笑

## 流程教训（V1→V7 沉淀）

1. **PIL 后处理 = 斑点源**（盖带硬边贴块/位置微偏成白色小方块）→ 已全废弃
2. 模型对"眼线方向变化"完全不可控（10+ 次失败）→ 情绪以姿态+嘴线表达
3. 模型对"嘴平线/下撇"部分可控但会反复微笑 → prompt 强调"不笑/放松平线"
4. 模型会自作主张加异物（口水/汗珠/黑斑/条纹）→ prompt 禁词 + 出图后单查
5. **姿态与条纹绑定**：盘腿交叠手姿态 4 次生成必出黑白条纹爪 → 困倦改用站立低头打盹
6. **色彩漂移**：单参考图生成色彩会整体偏浅偏粉 → 双参考图（+色卡）+ P8 色彩检测
7. 模型对"画面左/右"理解易镜像（满足版连续 3 次左右反）→ prompt 用"画面左侧/右侧"表述
