# lala 情绪库 V2（线条情绪 + 自然动作）

> 用途：lala 表情/情绪延展的唯一规格。与 lala-drawing-guide.md（画法规格）、§2.8（识别锁定）配合。
> 制作日期：2026-09-10 ｜ 方法：image_edit 生成姿态 + PIL 斑色定位眼线/嘴线

## 核心方法（V3 最终版，已跑通）

1. **姿态由 image_edit 生成**（模型强项）：指定情绪姿态（坐/瘫/站/抬手）+ 纯色米白背景，参考 lala-main-v4
2. **眼线方向 = PIL 斑色定位替换**（模型画不出斑内眼线方向——已验证死路）：
   - **斑色聚类定位**（关键改进）：找色值 (39,34,22)±20 且 y<520 的像素，按 x 中位聚成左右两簇，眼线直接画在**簇中心**（面中偏移法会被背景米白污染导致偏位——已弃用）
   - 盖带：26×12px 椭圆用**斑色**填充，再画 9px 近黑弧线；只动小条带，不整脸重涂
3. **嘴线也 PIL 统一画**（模型对"嘴平线/嘴角下撇"免疫——3 次生成全是微笑）：
   - 嘴定位：斑簇 y 均值 +58 附近行扫描找深色线（v4 嘴-斑距基准）
   - 盖带 48×18 面中米白 + 8px 近黑线（平线/下弧/圆点）
4. **斑点清理**：prompt 加"纯色米白背景干净无斑点"+ 生成后连通域删 <250px 独立小簇（防误伤毛发纹理）

## 流程沉淀（V1→V3 教训）

1. 模型对"嘴平线/嘴角下撇"免疫（3 次全微笑）→ 嘴必须 PIL 画
2. 面中米白聚类会被背景污染（面中与背景色差仅 3-4）→ 眼线/嘴定位一律用**斑色聚类**
3. 眼线盖带用斑色（39,34,22 附近实测）、嘴盖带用面中米白（253,250,225）
4. 姿态生成时加"纯色米白背景、画面干净无斑点"；歪头/侧头姿态会让自动定位失效，优先正面姿态
5. 斑点清理用连通域删小簇（<250-300px），不用邻域计数法（会误删毛发纹理）
