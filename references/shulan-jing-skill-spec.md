## 2.8 IP 识别度锁定条例（V0.7，用户强制，最高优先级）

**目的：lala 每一版形象本体必须一致，禁止一版一个样、形象漂移。**

✅ 识别特征锁定（每版生成必须全部保持，缺一即重绘）：
1. **毛色**：灰黑深棕大地色（短毛色块），头背深→四肢暖灰褐→腹/面中暖米白三层柔和渐变；❌ 禁止漂移为棕褐、橙红、绿、蓝等任何其他色（曾出现漂移为棕褐熊色）
2. **长爪**：修长手臂 + 白色爪尖（识别度最高的局部特征）
3. **脸部**：单根极简眼睑弧线 / 闭眼浅笑；**墨镜斑（V0.9 特点版锁定，用户方案C）**：眼周一圈固定形状深棕黑斑块（对称椭圆像天然墨镜，最强记忆点），斑内嵌单线弧眼，面部其余为暖米白浅色区，与墨镜斑强对比；❌ 禁止出现大圆眼、腮红
4. **身形**：抽象极简人形树懒，头身比稳定
5. **气质**：松弛、放空、冷感，去可爱化

✅ 道具规则（用户指定）：
1. **三件套（咖啡杯/帆布托特包/挂钟）不再作为识别锚点，不再默认使用**；用户明确"三件套不用"
2. 道具仅按场景需要作可选点缀，且不得抢主体、不得改变识别特征
3. 场景道具（草帽、书本、餐具等）由用户每版指定，不属于 IP 识别锁定范围

✅ 每版自检必做"识别度对比"：出图后与权威图（theme-style.jpg）核对毛色/长爪/脸部/身形四项，任何一项漂移即不合格、强制重绘，不得交付。**自动校验通道（V0.8.1）：调用 ip-identity-verifier skill（ip_identity_checker.py），综合辨识度 ≥86% 判定通过、<86% 强制重绘**；语义分由 LLM Read 两图比对五维后传入。

⚠️ **特点版校验口径（V0.9 补充）**：墨镜斑为已锁定特点，会改变面部色区占比——此类"特点强化版"机器视觉分按新基线（主体像 v4 = 83.6、三视图 v4 正面视图 ≈86），语义比对（毛色/长爪/墨镜斑/身形/气质）通过即可判定达标；校验器语义维度将"墨镜斑"计入识别点。版面类图（三视图/设定页）按单视图裁切校验，不以整图为准。
