# 树懒精 SlowLab Skill Spec V0.10

> 用途：AI生成IP图案、印花、logo，文创产品：帆布托特包、线圈本、吊牌、贴纸；小红书社媒配图、电商物料
> 定位：松弛时尚风，拒绝低幼Q版、萌系可爱风格，去可爱化
> 核心原则：所有视觉产出必须保持原创性。允许参考外部作品的气质、材质、排版节奏与氛围，但禁止直接复制其他作品角色造型、五官结构、身体比例、构图关系、标题文字排布、标志性视觉元素。

## 1. IP基础人设｜角色锁定

树懒精SlowLab，慢生活主题IP家族，抽象极简人形树懒。

**IP 家族设定（V0.10，用户锁定）**：权威形象（references/lala-main-v4.png 主体像 + references/lala-turnaround-v4.png 三视图，V4 特点版，已替换原 theme-style.jpg）为树懒精家族成员之一，角色名 **lala**。后续扩展家族其他成员时，共享家族视觉语言（大地色渐变毛色/墨镜斑/白尖爪/松弛冷感气质），各自拥有独立名字与细节差异，禁止全部一样化。

✅固定形象锚点（lala）：
1. 肢体：长爪下垂；优先姿态：半躺、松弛倚靠，其次缓慢站立；❌禁止悬挂吊在树上造型
2. 面部：极简单根眼睑弧线；无大圆眼睛、无腮红，面部大量留白，克制简约
3. 道具：不设固定标志道具（三件套咖啡杯/帆布托特包/挂钟已按用户要求停用，见 §2.8）；场景道具按每版用户指定作可选点缀，不能抢夺IP主体视觉重心
4. 气质：松弛舒展，不内卷，安静放空，带有淡淡的冷感，拒绝甜腻卖萌

## 2. 视觉强制规则

### ✅必须遵守
1. 轮廓干净利落，线条可控，适合面料数码印花，避免细碎短线（防止印刷断线）
2. 配色规则（V0.5 起松绑，用户新约束）：
   - **IP 形象颜色可自由发挥想象**，不受色板硬锁；但想象必须符合美学 skill（aesthetic-foundations）的要求与内容——明度层级成立、面积对比合理、低饱和为主、暖调统一、不出现高饱和糖果色/杂色堆砌。
   - **背景与版式**仍以固定色板为主：炭黑 #0B0908｜暖米白 #CCBFB8｜雾灰 #D0D7D6｜深炭绿 #1F231C｜咖啡棕 #3C3327（拓展纸感配色仅绘本风格启用：旧纸米白 #E8DFCF｜淡灰褐 #B8AFA3｜铅笔灰 #6E6E6E）
   - **线条形态**：IP 形象线条造型"类似即可、不要全部一样化"——保持统一风格气质（手绘绘本风），但每幅作品的轮廓、细节、比例允许自然差异，禁止机械复读同一形象。
3. 画面留白充足，背景尽量简洁干净

### ❌强制禁止
1. Q版、幼态萌系、大圆可爱眼睛、腮红、毛茸茸毛绒质感
2. 3D黏土玩偶、厚重渲染、复杂渐变高光
3. 密集细碎线条、繁杂背景、大量多余装饰
4. 树懒悬挂吊在树上的造型
5. 直接复刻外部绘本角色造型、构图、标志性五官

## 2.5 风格方向（4套可选，每次生成选定其中一种）

### A.极简潮玩风 ｜ B.印花图案风 ｜ C.电商产品图风 ｜ D.原创手绘绘本风

D.原创手绘绘本风：借鉴绘本纸张氛围，仅学习质感气质，严格守住原创边界。可借鉴：米白旧纸底、纸张颗粒、彩铅/蜡笔手绘线条、粗粝手绘边缘、拼贴质感，安静松弛留白。树懒精保持原有抽象人形设定：长爪下垂、极简单眼睑弧线，无大圆眼，姿态优先半躺倚靠。

## 2.6 IP 主题形象锚定（V0.10 已替换，用户锁定）

**lala 形象模板 = V4 特点版**，权威参考文件：
- 主体像：`references/lala-main-v4.png`（正面全身标准像，**替代原 theme-style.jpg**）
- 三视图：`references/lala-turnaround-v4.png`（正/侧/背设定稿，网格+标准色卡）
所有风格方向（A/B/C/D）与所有场景衍生共用此形象基调。

✅ IP 形象细节锚点（以 V4 主体像为准，每版必保）：
1. 形态：拟人树懒，正面全身直立/微含胸、重心低、松弛；头身比稳定；四肢修长
2. **墨镜斑（最强记忆点）**：眼周对称深棕黑斑块（像天然墨镜），斑内嵌单根极简眼睑弧线（闭眼）
3. 面部：面中暖米白浅色区与墨镜斑强对比；极简小鼻；嘴极简短弧线浅笑
4. **白尖爪**：四肢末端细爪带白色尖甲（识别度最高局部特征；单图生成失败时以三视图 v4 为基准）
5. 毛色：炭黑→暖灰褐→暖米白三层柔和渐变（头背深/四肢暖褐/面中腹浅），水彩晕染式无硬分界
6. 质感：米白旧纸底、纸张颗粒、彩铅蜡笔排线、低饱和哑光、大量留白
7. 品牌字标（可选）：主题/传播场景可带 "SlowLab"+"慢生活树懒精" 字标；纯印花图案默认无文字

❌ 原创边界（禁止复制）：
1. 禁止照搬原 theme-style.jpg 的构图关系、枝干角度与走向（该图已归档 outputs/archive/theme-style-historical.jpg，仅作设计来源参考）
2. 禁止复制"趴枝干"场景设定（衍生场景需更换姿态/场景，仅继承形象细节气质）
3. 禁止使用来源水印
4. 形象细节统一（墨镜斑/白尖爪/渐变毛/神态气质），但姿态、场景、动作允许自然变化，禁止机械复读同一画面

## 2.8 IP 识别度锁定条例（用户强制，最高优先级）

✅ 识别特征锁定（每版生成必须全部保持，缺一即重绘）：
1. **毛色**：灰黑深棕大地色，头背深→四肢暖灰褐→腹/面中暖米白三层柔和渐变；❌ 禁止漂移为棕褐、橙红、绿、蓝等任何其他色
2. **长爪**：修长手臂 + 白色爪尖（识别度最高的局部特征）
3. **脸部**：单根极简眼睑弧线 / 闭眼浅笑；**墨镜斑（V0.9 特点版锁定）**：眼周深棕黑对称斑块（像天然墨镜，最强记忆点），斑内嵌单线弧眼；❌ 禁止大圆眼、腮红
4. **身形**：抽象极简人形树懒，头身比稳定
5. **气质**：松弛、放空、冷感，去可爱化

✅ 道具规则：三件套（咖啡杯/帆布托特包/挂钟）不再作为识别锚点；道具仅按场景需要作可选点缀。

✅ 每版自检必做"识别度对比"：与权威图（references/lala-main-v4.png）核对墨镜斑/白尖爪/毛色渐变/脸部/身形，任何一项漂移即不合格、强制重绘。**自动校验通道：ip-identity-verifier（ip_identity_checker.py）综合辨识度 ≥86% 判定通过、<86% 强制重绘**；语义分由 LLM 比对五维后传入。

⚠️ **特点版校验口径（V0.9）**：墨镜斑改变面部色区占比是预期，语义比对（毛色/长爪/墨镜斑/身形/气质）通过即达标；版面类图（三视图/设定页）按单视图裁切校验，不以整图为准。

## 2.9 流程效率优化条例（V0.8）

1. P1 Prompt 模板化：固定块（A 形象锚点/B 质感/C 肢体/D 文字/E 水印/F 色板/G 负面）+ 场景变量段（50~120字），交付不重复全量固定块。
2. P2 两级校验：L0 快筛（预览描述/OCR）→ L1（下载原图+坐标裁切核对）。L0 失败直接重绘。
3. P3 增量重绘：只强化失败维度（优先级：文字>遮挡>毛色>肢体>道具>水印）。
4. P4 遮挡类需求：prompt 双保险 + PIL 后处理兜底。
5. P5 局部编辑限制：仅单变量微调，编辑后必查文字。
6. P6 参考图精简：形象延展 = core-ip + lala-main-v4 双参考；纯形象 = lala-main-v4 单参考。
7. P7 交付归档分流：用户侧精简6项+校验行；全量进归档。

## 5. 输出交付格式（V0.8 精简版）

固定输出 6 项 + 校验结论行（正向Prompt摘要/负面Prompt引用/图案类型/推荐画布比例/工厂印刷备注/适用产品 + 校验行）。

## 6. 生成后自检校验规则（V0.8 两级校验）

L0 快筛：文字/元素增减/明显肢体错乱/毛色漂移。L0 全过 → L1 精检：坐标裁切核对、松弛气质、色彩美学、线条印花、主体清晰、姿态合规、原创校验、识别度对比。L0 失败直接重绘；L1 任一失败按 P3 增量重绘。

## 6.1 动作校准与定稿复检（V0.6）

- 肢体数量硬校验（恰好4肢）；结构自然；姿态有支撑；道具不抢主体；禁止悬挂树上
- 定稿必再过完整复检，不合格强制重绘；复检须下载原图+裁切放大核对（V0.6.1），不得仅凭摘要
- 过程校验不合格最多重试3次；3次失败输出并标注人工复核
