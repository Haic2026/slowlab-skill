# 树懒精 SlowLab Skill Spec V0.7

> 用途：AI生成IP图案、印花、logo，文创产品：帆布托特包、线圈本、吊牌、贴纸；小红书社媒配图、电商物料
> 定位：松弛时尚风，拒绝低幼Q版、萌系可爱风格，去可爱化
> 核心原则：所有视觉产出必须保持原创性。允许参考外部作品的气质、材质、排版节奏与氛围，但禁止直接复制其他作品角色造型、五官结构、身体比例、构图关系、标题文字排布、标志性视觉元素。
> 版本说明：草稿迭代中，定稿后升级V1.0，不随意改动

## 1. IP基础人设｜角色锁定

树懒精SlowLab，慢生活主题IP家族，抽象极简人形树懒。

**IP 家族设定（V0.7，用户命名）**：权威形象（references/theme-style.jpg）为树懒精家族成员之一，角色名 **lala**。后续扩展家族其他成员时，共享家族视觉语言（大地色毛色/三件套道具/松弛冷感气质），各自拥有独立名字与细节差异，禁止全部一样化。

✅固定形象锚点（lala）：
1. 肢体：长爪下垂；优先姿态：半躺、松弛倚靠，其次缓慢站立；❌禁止悬挂吊在树上造型
2. 面部：极简单根眼睑弧线；无大圆眼睛、无腮红，面部大量留白，克制简约
3. 标志道具：咖啡杯、帆布托特包、简约挂钟；道具作为点缀，不能抢夺IP主体视觉重心
4. 气质：松弛舒展，不内卷，安静放空，带有淡淡的冷感，拒绝甜腻卖萌

## 2. 视觉强制规则

### ✅必须遵守
1. 轮廓干净利落，线条可控，适合面料数码印花，避免细碎短线（防止印刷断线）
2. 配色规则（V0.5 起松绑，用户新约束）：
   - **IP 形象颜色可自由发挥想象**，不受色板硬锁；但想象必须符合美学 skill（aesthetic-foundations）的要求与内容——明度层级成立、面积对比合理、低饱和为主、暖调统一、不出现高饱和糖果色/杂色堆砌。
   - **背景与版式**仍以固定色板为主：
     炭黑 #0B0908｜暖米白 #CCBFB8｜雾灰 #D0D7D6｜深炭绿 #1F231C｜咖啡棕 #3C3327
     拓展纸感配色（仅绘本风格启用）：旧纸米白 #E8DFCF｜淡灰褐 #B8AFA3｜铅笔灰 #6E6E6E
   - **线条形态**：IP 形象线条造型"类似即可、不要全部一样化"——保持统一风格气质（手绘绘本风），但每幅作品的轮廓、细节、比例允许自然差异，禁止机械复读同一形象。
3. 画面留白充足，背景尽量简洁干净
4. 主题视觉元素：咖啡、帆布包、简约挂钟，呼应慢生活内核

### ❌强制禁止
1. Q版、幼态萌系、大圆可爱眼睛、腮红、毛茸茸毛绒质感
2. 3D黏土玩偶、厚重渲染、复杂渐变高光
3. 密集细碎线条、繁杂背景、大量多余装饰
4. 树懒悬挂吊在树上的造型
5. 直接复刻外部绘本角色造型、构图、标志性五官

## 2.5 风格方向（4套可选，每次生成选定其中一种）

### A.极简潮玩风
干净利落轮廓，简约平面2D图形，适合做小标、吊牌、品牌LOGO。线条克制，色块平整。

### B.印花图案风
适配帆布包、线圈本大面积印花，主体稳定，图形可单独提取，线条满足工厂印花生产要求。

### C.电商产品图风
IP图案放置在实物场景（托特包/本子）上，光影柔和，用于小红书商品图、店铺详情，突出产品质感。

### D.原创手绘绘本风
借鉴绘本纸张氛围，仅学习质感气质，严格守住原创边界。
可借鉴：米白旧纸底、纸张颗粒、彩铅/蜡笔手绘线条、粗粝手绘边缘、拼贴质感，安静松弛留白。
**严禁**：照搬参考绘本脸部特写构图、绿色圆眼、橙色身体造型、书名文字排版、角色比例。
树懒精保持原有抽象人形设定：长爪下垂、极简单眼睑弧线，无大圆眼，姿态优先半躺倚靠。

## 2.6 IP 主题形象锚定（权威参考，用户指定）

**这张图为 IP 主题形象权威**，参考文件：`references/theme-style.jpg`（用户指定"以这张图片为 IP 主题形象，细节以它形象为主旨"）。所有风格方向（A/B/C/D）与所有场景衍生共用此形象基调。

✅ IP 形象细节锚点（以权威图为准）：
1. 形态：树懒趴在棕绿相间的枝干上休憩，或倚靠支撑物；肢体放松舒展
2. 神态：闭眼放空、面带浅淡笑意、慵懒松弛（拒绝大眼卖萌）
3. 毛色与质感：大地色系（灰黑/深棕/暖褐）+ 深绿色调；质朴柔和、低饱和哑光
4. 道具三件套样式（以图中样式为参考）：棕色咖啡杯、棕色手提袋（帆布托特包）、复古圆形时钟；小尺寸点缀
5. 氛围：舒缓闲适、慢生活、大量留白；纸张颗粒、彩铅/蜡笔线条、粗粝手绘边缘
6. 品牌字标（可选）：主题/传播场景可带 "SlowLab"+"慢生活树懒精" 字标；纯印花图案默认无文字

❌ 原创边界（禁止复制）：
1. 禁止照搬权威图的构图关系、枝干角度与走向
2. 禁止复制画面中"趴枝干"这一具体场景设定（衍生场景需更换姿态/场景，仅继承形象细节气质）
3. 禁止使用图上的来源水印（如"豆包AI生成"）
4. 形象细节统一（毛色/道具/神态气质），但姿态、场景、动作允许自然变化，禁止机械复读同一画面

## 6. 生成后自检校验规则

AI出图完成，必须逐条自检，不符合则重新生成prompt
1. 是否符合树懒精SlowLab极简松弛气质，没有幼态可爱化
2. IP形象颜色是否符合美学 skill 要求（明度层级/面积对比/低饱和/暖调统一）；背景版式是否遵循固定色板，无额外杂色
3. 线条是否干净，不存在大量细碎短线，适合印花生产
4. 主体清晰，道具仅作为点缀，不会盖过IP形象
5. 姿态合规：禁止树上悬挂造型
6. 原创校验：不存在抄袭外部绘本角色造型、构图、标志性五官

## 6.1 动作校准与定稿复检（V0.6 升级）

触发：图片生成完成后立即执行；**每次最终定稿后必须再执行一次完整复检**（用户强制要求）。

校验项：
1. **肢体数量硬校验（数值化）**：恰好 4 肢（双臂/长爪 2 + 双腿 2）；出现多余手臂、多余爪子、第三只脚、重复腿部、腿部交叠错乱 → 一律判不合格
2. 肢体结构：连接自然、无畸形穿插
3. 姿态合理性：有支撑、重心稳定、符合松弛气质；禁止夸张杂技、大幅度扭曲
4. 道具校验：道具与肢体接触自然，无漂浮、穿模；仅点缀不抢主体
5. 禁止动作：严禁悬挂树上、攀爬树枝

定稿复检规则（新增）：
- 最终稿（含重试后定稿）必须再过一次完整动作校准，输出复检报告
- **定稿复检不合格 → 强制重绘**，不得以"已达重试上限"为由跳过；重绘后再次复检
- 复检报告随交付一并输出（阶段/是否通过/问题/修正/是否重生成）
- **复检手段（V0.6.1）**：下载原图核对；肢体区域轮廓不清晰时，必须裁切放大局部再核对（四肢数量/结构），不得仅凭生成摘要判定通过

重试规则：
- 过程校验不合格 → 记录问题 → 自动改写 prompt 修复 → 重新生成 → 再次校准；最多重试 3 次
- 3 次失败输出图片并标注人工复核；定稿复检不合格无论重试次数强制重绘
