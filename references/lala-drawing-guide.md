# lala 画法规格书（V1，基于 V4 主体像实测）

> 数据来源：references/lala-main-v4.png（1024×1024 像素级实测）+ references/lala-turnaround-v4.png（白尖爪基准）
> 用途：任何出图/延展时，按本规格控制各肢体大小、爪子样式、头部形状、配色；与 §2.6/§2.8 配合使用。
> V1.2：爪子条例改为黑线爪（用户 2026-09-10 指定）；新增 §6.2 左右臂配色条例

## 1. 总体比例（以 1024 画布 / 主体总高 813px 为基准）

| 部位 | 实测尺寸(px) | 占比(相对全身高813) | 说明 |
|---|---|---|---|
| 全身主体 | 宽 486 × 高 813 | 100% | y 从 110 到 923，左右居中 |
| 头部（含毛发） | 宽 434 × 高 359 | **高 44%** | 头大身短、圆整；中心约 (466,314) |
| 身体（躯干） | 宽 486 × 高 428 | **高 53%** | 圆润椭圆，中心约 (494,695)，y 471-899 |
| 手臂 | 宽 ~60 × 长 360 | 长 44% | 从肩 y561 垂落到 y921，粗 28-30px |
| 爪 | 宽 371(两爪) × 高 102 | 高 12% | y 821-923，末端深色细爪 |

**头身比记忆点**：头高 : 躯干高 ≈ 1 : 1.2（头占近半身，圆润萌底+墨镜斑冷感对冲，这是 lala 的辨识度构成）。

## 2. 头部画法（圆整规格）

1. 轮廓：椭圆，**宽高比 ≈ 1.21 : 1**（434×359），圆润饱满但不滚圆
2. 毛发边缘：头缘一圈**短排线笔触**（8-16px 短线段，模拟彩铅），制造"毛发包裹脸"的层次
3. 头顶两侧：**圆耳**（各约 76×112px，贴头缘、与头重叠、内耳浅一档）
4. 面中区：椭圆约 165×150px（y 210-350，x 440-585 区域），暖米白，与周围深色毛发形成强对比
5. 下巴/面底：面区底部收窄衔接（梨形感：上宽下窄）

## 3. 墨镜斑规格（最强记忆点）

1. 两枚对称椭圆斑：各约 **54×56px**，中心分别在面中左右两侧（左 ~(468,281)、右 ~(556,281)）
2. 色：深棕黑 **(39,34,22)**
3. 斑内嵌**单根极简眼睑弧线**（闭眼），线宽 8-10px，近黑 (26,20,15)
4. 斑内缘（靠鼻侧）做**柔和晕染**（与面中米白区过渡，不生硬）
5. 两斑间距（鼻梁宽）约 35-40px

## 4. 爪子样式（V1.2 起黑线爪）

1. 手臂：从肩部自然垂落，**细长**（长 360px、粗 28-30px），微内收
2. 爪：末端 **2-3 根细长爪指**（每根长约 45-55px、粗 8-10px）
3. **黑线爪（用户指定 V1.2）**：爪指整体深棕黑，无白色尖甲；与三视图 v4 白尖基准冲突时以用户最新指定（黑线爪）为准
4. 爪色：深棕黑 (42,32,22)

## 5. 配色表（V4 实测）

| 部位 | 色值 | 说明 |
|---|---|---|
| 头部毛发 | (55,46,31) | 深棕，炭黑-暖褐过渡的深端 |
| 身体/躯干 | (78,74,56) | 灰褐偏暖，比头浅半档 |
| 手臂（左） | (141,132,114) | 灰褐偏冷（画面左侧） |
| 手臂（右） | (165,108,68) | 暖棕红（画面右侧，V6 实测） |
| 墨镜斑 | (39,34,22) | 深棕黑（斑+眼线近黑 (26,20,15)） |
| 面中区 | (253,250,225) | 暖米白（近白） |
| 爪指 | (42,32,22) | 深棕黑 |
| 背景 | (253,248,227) | 米白纸底 |

**配色规则**：整体暖调统一、低饱和；明度层级 = 面中(亮) > 身体(中) > 头/手臂(中深) > 斑/爪(深)；面积对比 = 米白面区与深棕主体约 1:3。**左右臂不对称（左灰右红）是 lala 特征**。

## 6. 画法要点（线条）

1. 线条：彩铅/蜡笔排线，粗粝手绘边缘；线宽主体 6-12px，禁止细碎短线
2. 渐变：头背深→四肢暖褐→面中/腹米白，水彩晕染式无硬分界
3. 大量留白；主体约占画面 60-70%
4. 无文字、无水印、无署名

## 6.1 爪子形式统一条例（V1.2，用户强制，黑线爪版）

1. **全图所有爪子形式必须完全一致**：统一为「黑色细长爪」（黑线爪，无白色尖甲）
2. **禁止混合**：同一张图/同一组图内，禁止出现白尖爪与黑线爪并存
3. prompt 强制句："所有四肢爪子统一为黑色细长爪（黑线爪），爪子没有白色尖甲，四爪形式完全一致，禁止白尖爪"
4. 出图后必查：逐张核对爪尖为黑色、无白尖混入；发现白尖/黑白条纹 → 重绘

## 6.2 左右手臂配色条例（V1.2，用户强制）

1. **左右手臂颜色必须分明**：画面左侧手臂灰褐色（偏冷灰 (141,132,114) 附近）、画面右侧手臂暖棕红色（偏红暖 (165,108,68) 附近），与权威图 lala-main-v4 一致
2. **禁止两臂同色**；模型对"角色左右"理解易镜像（满足版连续 3 次左右反）——prompt 用"画面左侧/画面右侧"表述，出图后程序检测 L-RG / R-RG 差值确认
3. 镜像兜底：检测到方向反 → 区域色互换（mask 红/灰臂像素，互换中位色，保留形状），或按"画面左/右"重生成

## 7. 快速检查清单（出图后用）

- [ ] 头高约占全身 40-48%（不细长、不滚圆）
- [ ] 墨镜斑两枚对称、色深棕黑、斑内单线弧眼
- [ ] **所有爪子统一为黑线爪（无白尖混入、无黑白条纹）**
- [ ] **左右手臂颜色分明：左灰褐、右暖红**
- [ ] 配色在实测色值 ±20% 内（不漂移棕褐/橙红/绿蓝）
- [ ] 面中米白与斑强对比
